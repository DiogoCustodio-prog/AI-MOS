# Material-fonte

Esta área preserva exportações e referências históricas usadas durante a concepção do AI-MOS.

## Status

Os arquivos aqui são **material-fonte não normativo**. Eles podem conter:

- conversas exportadas;
- versões repetidas de uma mesma proposta;
- decisões já revisadas;
- ideias ainda não aprovadas;
- estruturas de diretórios aspiracionais;
- exemplos de comandos e integrações que ainda não existem neste workspace.

Nenhum arquivo desta área deve ser tratado automaticamente como **Source of Truth**. Antes de reutilizar qualquer informação, compare-a com os documentos canônicos em `SYSTEM/`, `FOUNDATION/`, `CORE/`, `BOOTSTRAP/`, `CLIENTS/` e `KNOWLEDGE/`, conforme o domínio.

## Preservação

As exportações são mantidas sem edição para preservar contexto e histórico. A organização física dos arquivos não altera sua autoria, conteúdo ou status original.

## Conteúdo

- `chatgpt-exports/` — exportações de conversas utilizadas como insumo de arquitetura, governança, marketing e operação.

Quando uma decisão ou regra for validada, ela deverá ser formalizada em um documento canônico separado, com metadados YAML, ID estável, versão e relações relativas conforme o padrão AI-MOS.
